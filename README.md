# DX11Engine
A rendering engine using DirectX11. (learning project)

Current features :
- Load a 3D model (tested for obj and fbx mostly)
- Blinn-Phong shading with forward rendering
- Display the model with textures, normal maps and specular maps if they are present (otherwise use the material's diffuse color)
- Basic FPS camera controls
- Debug UI to control the directional light, switch to unlit or normal views or modify the camera speed
